# ShopBot — Client Deploy Playbook

Краткий плейбук для быстрого внедрения ShopBot под клиента.

## 1) До деплоя — входные данные

- [ ] Telegram токен от `@BotFather`.
- [ ] `ADMIN_IDS` (кто управляет магазином в Telegram).
- [ ] YooKassa credentials:
  - `YUKASSA_SHOP_ID`
  - `YUKASSA_SECRET_KEY`
- [ ] URL возврата/подтверждения платежа (если используется в сценарии клиента).
- [ ] Базовый каталог товаров для первичного наполнения.

## 2) Деплой

- [ ] Клонировать репозиторий и создать `.env` из `.env.example`.
- [ ] Заполнить обязательные переменные (`TELEGRAM_BOT_TOKEN`, `ADMIN_IDS`, `YUKASSA_*`, `DB_PATH`).
- [ ] Установить зависимости и подготовить окружение:
  - `python3 -m venv venv`
  - `venv/bin/pip install -r requirements.txt`
- [ ] Убедиться, что systemd-юниты настроены (`shopbot`, `shopbot-web`).
- [ ] Перезапустить сервисы:
  - `systemctl restart shopbot shopbot-web`

## 3) Живой smoke

- [ ] Проверить `/start` в Telegram.
- [ ] Проверить `/catalog` и открытие карточки товара.
- [ ] Для платежей: создать тестовый заказ и убедиться, что генерируется ссылка оплаты.
- [ ] Проверить веб-админку (`/login`) и вход под админским паролем.

## 4) Передача клиенту

- [ ] Передать доступы по безопасному каналу (сервер, бот, админка).
- [ ] Передать список админ-команд и базовые операционные инструкции.
- [ ] Зафиксировать контакт для инцидентов и окно поддержки.
- [ ] Отдельно проговорить честные ограничения (rate limits Telegram, внешняя зависимость от YooKassa API).
